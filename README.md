Car Dealership Platform (Full-Stack Capstone)

Full-stack web application to browse car dealerships, read customer reviews and post new ones. Built as the capstone of the IBM Full Stack Software Developer Professional Certificate.

✨ Features
User registration, login and logout (Django authentication)
List of dealerships, filterable by state
Dealer detail page with customer reviews
Add a review for a dealership (logged-in users)
Sentiment analysis of reviews (positive / neutral / negative)
Car inventory linked to each dealer
Containerized with Docker and deployable on Kubernetes
🛠️ Tech stack
Layer	Technology
Frontend	React, HTML, CSS
Backend	Django (Python)
Microservices	Node.js / Express, MongoDB
Deployment	Docker, Kubernetes
